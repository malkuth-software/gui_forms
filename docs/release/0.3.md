# 0.3 release notes: Themeable

0.3 was a stage, not a tagged release: its content shipped in builds of the
0.2 series (`v0.2.N`) as it landed, and is part of the
[0.5 seal](0.5). It made themes data.

## What it delivered

- **The theme engine.** Themes are data: properties, layered effects,
  transitions, state machines and bounded expressions over named parts. An
  idle window still draws nothing. Gate: identical pixels on every host and
  no frames once a window settles.
- **The theme language.** CSS-syntax sheets addressed to named parts, with
  selectors, colour and text roles, `@media`, motion, packages and imports,
  custom properties, user themes, and effects named from a registry the
  compiler checks ([The theme language](../user/theme-language)).
- **The GUI.Forms theme**, light and dark, written in the theme language
  over a floor of `:family()` blocks.
- **Familiar themes** recreating the looks of Windows 2000 (`classic`), XP
  (`xp-style`), Windows 7 (`windows7-style`) and macOS (`macos-style`)
  ([Themes](../user/themes)).
- **Compositor cooperation:** window backdrops as a chain (`blur`,
  `saturate`, `tint`), glass and reflections, on Windows, macOS and X11
  ([Transparency](../user/transparency)).
- **One CPU renderer:** `stx_skia`, the pruned CPU derivative of Skia, is
  the one renderer on every host, with every third-party source in the stx
  repository.
