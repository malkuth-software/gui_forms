# 0.5 release notes: the ABI and API seal

0.5 is the internal candidate that finalised the ABI, the API and the
languages. The owner declared it done on 2026-11-08; its last checkpoint
(22, pull request #473) merged on 2026-11-09. It was not tagged separately:
builds of the 0.2 series (`v0.2.N`) carry it. After 0.5, a change to a
sealed interface needs a recorded owner decision, and the C ABI's
breaking-change audit is blocking.

## What is sealed

- **The C ABI, version 1.1:** installed and versioned, with an error
  model, a breaking-change audit of its function tables against a recorded
  baseline, a conformance kit for native consumers
  ([The C ABI conformance kit](../user/c-abi-conformance-kit)), and C#
  interop over it. It covers the application, rules, sub-surfaces and the
  splashscreen.
- **Properties as capabilities:** every property is a cell, a view or a
  collection cell with one spelling, `(*c).text = "OK"` to write and
  `.read()` to read, typed conversions through `as_type`, and child
  properties such as `(*grid).area[*c]`. Getter and setter pairs for
  properties are gone ([Properties](../user/properties)).
- **The application, its windows and rules:** `Application::create`, one
  current application whose theme compiles once, the window a form
  generates as a `Window` subclass bound at construction, and window rules
  over a closed vocabulary
  ([The application and its windows](../user/application-and-windows),
  [Rules](../user/rules)).
- **Window kinds:** Window, Popup and Splash, with the splashscreen API and
  the hosts' `transient_surfaces` capability
  ([Overlays, Popups and Splash](../user/overlays-popups-and-splash)).
- **The form language:** `.form` documents, in-slot bindings, generated
  window and user-control classes, and the refusals that keep colours,
  fonts and program code out of documents ([Forms](../user/forms)).
- **The theme language and effects:** selectors, specificity and origins,
  `:family()`, backdrops, inline styles and user themes
  ([The theme language](../user/theme-language)).
- **Sub-surfaces:** threaded regions of a window with their own input,
  effects and accessibility.
- **The creation-cost contract:** creating a window does no hidden work,
  enforced by a benchmark gate.

## Also in 0.5

- **Smooth scrolling:** a notched wheel, the scroll bar's arrows and track,
  and paging glide to their target; precise (trackpad) deltas apply at
  once; reduced motion makes every scroll instant
  ([Controls](../user/controls.md#scrolling)).
- **The window band:** a reserved, themed strip drawn over every plane at
  a window's outer edge.
- **Theme variants:** light and dark variants with an automatic colour
  scheme, a fallback to GUI.Forms' own theme for a scheme a theme lacks,
  GUI.Forms' own high-contrast palette, and `tools/relocate_colours.py`
  for moving colours out of form documents
  ([Colour schemes](../user/theme-language.md#colour-schemes)).
- **The familiar themes,** approved by the owner.
- **The reference application,** `examples/reference`, shows the sealed API
  in one program.
- **The setter audit:** the public setters left on controls are the
  members that are not properties.
- **Documentation** for properties, forms, themes and converting a Windows
  Forms application, and examples moved onto the 0.5 approach.

The switch of the default theme to `gui-forms`, decided with the seal,
landed just after it; see [Unreleased](unreleased).
