Plots
=====

The plots package's primitives in ``GUIForms::PlotPrimitives``: bulk series columns and leased views, the ring channel, scales, ticks, axes, the plot transform, envelope decimation, colormaps, picking, the view and gesture model, legend layout, signal programs and the batched mark painters.

.. cpp:function:: template <typename Source> ElementRange visible_range(const Source& source, double minimum, double maximum) noexcept

   The elements whose x lies in [minimum, maximum], plus one beyond each end, by binary search over a monotone source (NaN x sorts as it lies: the search tolerates gaps only where they do not hide the boundary, so a monotone column with gaps should hold NaN in y, not x).

.. cpp:var:: constexpr std::size_t pyramid_base

   Min-max levels over a series' y values (decimation stage 3). Level 0's buckets hold ``pyramid_base`` elements; each level's buckets join two of the level below. A bucket stores the element indices of its minimum and maximum (the earliest on ties), so its envelope keeps element order. Memory: at most one index per element in total (n/2 + n/4 + ... minima and maxima), reserved by reserve() for the column's capacity. Value: ``4U``.
