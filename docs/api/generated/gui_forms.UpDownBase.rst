gui_forms::UpDownBase
=====================

.. cpp:namespace:: gui_forms

.. cpp:class:: UpDownBase : public Panel

   ``#include <gui_forms/controls/up_down_base.hpp>``

   The shared base of the up-down controls: a text field with up and down buttons.

   :cpp:class:`UpDownBase <gui_forms::UpDownBase>` is the base of :cpp:class:`NumericUpDown <gui_forms::NumericUpDown>` and :cpp:class:`DomainUpDown <gui_forms::DomainUpDown>`, as Windows
   Forms names it. It holds the parts both are made of: an :cpp:func:`editor <gui_forms::UpDownBase::editor>` text box
   and the column of spin buttons beside it. It cannot be created on its own;
   create one of those controls instead, and use this type when code should
   work with either, for example to reach the field of any up-down control.

   *Status:* provisional. *Windows Forms counterpart:* ``UpDownBase``.

   :Properties:

      **editor** : ``std::shared_ptr<TextBox>``, read-only
         The :cpp:class:`TextBox <gui_forms::TextBox>` that shows and edits the value, created by the derived
         control as ``<stable_id>.editor``. Use it to set the font or to move
         focus to the field; focus given to the control goes to it.
