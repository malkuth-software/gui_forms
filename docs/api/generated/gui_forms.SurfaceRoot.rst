gui_forms::SurfaceRoot
======================

.. cpp:namespace:: gui_forms

.. cpp:class:: SurfaceRoot

   ``#include <gui_forms/surface_root/surface_root.hpp>``

   The root of one retained control tree and the thread that owns it.

   A :cpp:class:`SurfaceRoot <gui_forms::SurfaceRoot>` holds what every root of a control tree has, whatever
   presents it: the thread its tree belongs to, the queue of work posted to that
   thread, and the instrumentation counters its work reports into. A :cpp:class:`Window <gui_forms::Window>` is
   a surface root presented through a native host. A threaded sub-surface
   (stage S2) will be one whose frames go to a :cpp:class:`LiveSurface <gui_forms::LiveSurface>`. The root is bound
   to the thread that constructs it and never changes thread.

   The threaded sub-surfaces stage S1 moves the control-root part of :cpp:class:`Window <gui_forms::Window>`
   here step by step, with no change of behaviour. So far that is the thread
   identity, the dispatcher and the metrics.

   :Properties:

      **check_access** : ``bool``, read-only
         Whether the calling thread is the root's thread: the thread that
         constructed it.

      **invoke_required** : ``bool``, read-only
         The opposite of :cpp:func:`check_access <gui_forms::SurfaceRoot::check_access>`: whether the caller must post work with

      **dispatcher** : ``WindowDispatcher``, read-only
         A handle to this root's dispatcher that any thread may keep and post through after the root has closed (WindowDispatcher).

         mutations, damage, input, focus, disposals, wrong-thread rejections and
         more. ``MetricsSnapshot::to_json`` serializes it.

   .. cpp:function:: void set_dispatch_wake_handler(std::function<void()> wake)

      Installs the host's thread-safe wake. Installing one after work was
      queued wakes the host once at once. The handler runs under the
      dispatcher's lock on whichever thread posted, so it may only signal and
      must never call back into the root. Removing it while a synchronous
      :cpp:func:`invoke <gui_forms::SurfaceRoot::invoke>` waits throws ``std::logic_error``.
