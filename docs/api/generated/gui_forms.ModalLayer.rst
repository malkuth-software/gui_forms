gui_forms::ModalLayer
=====================

.. cpp:namespace:: gui_forms

.. cpp:class:: ModalLayer final : public Control, public ModalLayerCapabilities<ModalLayer>

   ``#include <gui_forms/controls/modal_layer.hpp>``

   In-window modal layer: any control shown centred over a scrim dimming its owner's window, taking every press outside it and holding focus, closed with a DialogResult through a cancellable closing.

   *Status:* provisional.

   :Parameters:

      **stable_id** : ``StableId``

   :Properties:

      **close_on_escape** : ``bool``
         Whether Escape inside the layer asks to close it as cancelled (through closing, which may refuse).

      **is_shown** : ``bool``, read-only

      **content** : ``Control::Ptr``, read-only
         The content while shown, else empty.

      **result** : ``std::optional<DialogResult>``, read-only
         The result of the last closing, or none before the first.

      **parts** : ``Parts``, read-only

   :Events:

      **closing** : ``Event<ModalLayerClosingEvent&>``

      **closed** : ``Event<DialogResult>``
