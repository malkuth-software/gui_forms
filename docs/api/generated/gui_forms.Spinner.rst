gui_forms::Spinner
==================

.. cpp:namespace:: gui_forms

.. cpp:class:: Spinner final : public Control, public SpinnerCapabilities<Spinner>

   ``#include <gui_forms/controls/spinner.hpp>``

   Indeterminate busy indicator: a ring of twelve dots, three lit, turning while active on the window's frame clock; still under reduced motion; busy to assistive technology.

   *Status:* provisional.

   :Parameters:

      **stable_id** : ``StableId``

   :Properties:

      **active** : ``bool``
         Whether the spinner shows and turns; an inactive spinner draws nothing and reports no busy state.

      **phase** : ``std::size_t``, read-only
         The first lit dot now, from twelve o'clock clockwise (0 while still).

      **moving** : ``bool``, read-only
         Whether the ring is turning: on the window's motion clock.

      **parts** : ``Parts``, read-only
