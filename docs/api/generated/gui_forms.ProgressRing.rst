gui_forms::ProgressRing
=======================

.. cpp:namespace:: gui_forms

.. cpp:class:: ProgressRing final : public Control, public ProgressRingCapabilities<ProgressRing>

   ``#include <gui_forms/controls/progress_ring.hpp>``

   Circular progress indicator of forty dots: lit in proportion to value over maximum, or a turning run while indeterminate, on the window's frame clock with reduced motion honoured.

   *Status:* provisional.

   :Parameters:

      **stable_id** : ``StableId``

   :Properties:

      **value** : ``double``
         The progress, from 0 to maximum; a value outside that range is drawn clamped to it. Not finite throws std::invalid_argument.

      **maximum** : ``double``
         The value of a full ring (100 by default). Not finite or not above zero throws std::invalid_argument.

      **indeterminate** : ``bool``
         Whether the ring shows activity without an amount: a turning arc instead of the value.

      **fraction** : ``double``, read-only
         value over maximum, clamped to [0, 1].

      **lit_dots** : ``std::size_t``, read-only
         The dots a determinate ring lights: fraction() of dot_count, rounded to the nearest dot (a positive fraction lights at least one).

      **phase** : ``std::size_t``, read-only
         The first dot of the turning run (0 while still or determinate).

      **moving** : ``bool``, read-only
         Whether the run is turning: on the window's motion clock.

      **parts** : ``Parts``, read-only
