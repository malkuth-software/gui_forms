gui_forms::ColorPicker
======================

.. cpp:namespace:: gui_forms

.. cpp:class:: ColorPicker final : public Control, public ColorPickerCapabilities<ColorPicker>

   ``#include <gui_forms/controls/color_picker.hpp>``

   Colour picker with a saturation-brightness field, a hue track, an optional alpha track and a swatch, picked by pointer drags or the keyboard.

   *Status:* provisional.

   :Parameters:

      **stable_id** : ``StableId``

      **initial_value** : ``Color``, default ``Color::rgba(255, 255, 255)``

   :Properties:

      **value** : ``Color``
         The picked colour; a change raises value_changed. Picking writes it; a program's write moves the thumbs (the hue is kept when the colour is grey).

      **alpha_enabled** : ``bool``
         Whether the alpha track is shown and the alpha can be picked; hiding it leaves the value's alpha as it is.

      **hsv** : ``ColorPickerHsv``
         The thumbs' position. set_hsv moves them and writes the value (alpha kept); it throws std::invalid_argument, changing nothing, for a non-finite component or one outside its range (hue 360 is taken as 0).

      **dragged_part** : ``ColorPickerPart``, read-only
         The part a pointer press is dragging, or none.

      **parts** : ``Parts``, read-only

      **states** : ``States``, read-only

   :Events:

      **value_changed** : ``Event<Color>``

      **value_committed** : ``Event<Color>``
         A pick finished: a drag's release or a key edit. Not raised by a program's write of :cpp:member:`value <gui_forms::ColorPicker::value>`.

   :Inherited:

      It also has every member of :cpp:class:`Control <gui_forms::Control>` and :cpp:class:`Component <gui_forms::Component>`: geometry, layout, visibility, focus, input routing, painting and disposal.
