gui_forms::ColorPicker
======================

.. cpp:namespace:: gui_forms

.. cpp:class:: ColorPicker final : public Control, public ColorPickerCapabilities<ColorPicker>

   ``#include <gui_forms/controls/color_picker.hpp>`` (:src:`source <include/gui_forms/controls/color_picker.hpp>`)

   A colour picker: a saturation and brightness field for the current hue, a vertical hue track, an optional alpha track and a swatch of the value.

   The swatch shows the value over a checkerboard, so transparency is visible.
   :cpp:class:`ColorDialog <gui_forms::ColorDialog>`'s hosts and :cpp:class:`ColorValueEditor <gui_forms::ColorValueEditor>`'s drop-down use the picker; use
   a :cpp:class:`ColorDialog <gui_forms::ColorDialog>` to ask for a colour in a dialog of its own.

   .. rubric:: Notes

   A primary press on the field, the hue track or the alpha track picks there
   and drags that part until the release; each move writes :cpp:member:`value <gui_forms::ColorPicker::value>`. With the
   keyboard, Left and Right move the saturation and Up and Down the brightness
   by 1/100 (1/10 with Shift); Page Up and Page Down move the hue by 5 degrees
   (30 with Shift); while :cpp:member:`alpha_enabled <gui_forms::ColorPicker::alpha_enabled>`, Home and End move the alpha by 1/16
   down or up, and Shift with Home or End sets it to 0 or 255. Each key edit
   writes the value and raises :cpp:func:`value_committed <gui_forms::ColorPicker::value_committed>`.

   The picker keeps its HSV position apart from the value, so a grey keeps the
   hue it was picked at. Every area is a theme part: ``field``, ``hue_track``,
   ``alpha_track`` and ``swatch`` are wells carrying their content colours,
   which the default and familiar themes draw as gradients over a
   checkerboard, in forced high contrast too; a theme without those rules
   draws plain wells. The thumbs are ``field_thumb``, ``hue_thumb`` and
   ``alpha_thumb``.
