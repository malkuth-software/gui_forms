gui_forms::Callout
==================

.. cpp:namespace:: gui_forms

.. cpp:class:: Callout final : public Control, public CalloutCapabilities<Callout>

   ``#include <gui_forms/controls/callout.hpp>`` (:src:`source <include/gui_forms/controls/callout.hpp>`)

   A teaching callout: a card pointing out a target control, with an optional bold title, wrapped text, a close mark and an optional action button.

   .. gf-preview:: controls/callout
      :alt: A Callout as the stock specimen shows it, in the windows-professional theme.

   It opens below its target (above with :cpp:member:`prefers_above <gui_forms::Callout::prefers_above>`), aligned to the
   target's leading edge and moved to the other side when the preferred one has
   no room, in an overlay of the target's window, and it follows the target
   when the window resizes. A callout is not modal. Use a :cpp:class:`ToolTip <gui_forms::ToolTip>` for a short
   hint on hover, and a :cpp:class:`ModalLayer <gui_forms::ModalLayer>` or a :cpp:class:`TaskDialog <gui_forms::TaskDialog>` when the user must
   answer before going on.

   *Status:* provisional.

   .. rubric:: Notes

   Without :cpp:member:`light_dismiss <gui_forms::Callout::light_dismiss>`, presses outside the callout reach the window as
   usual. With it, a press outside closes the callout and is not passed on.
   Focus moves into the callout when it opens (to the action button, else the
   callout) without being held there, and returns to where it was when it
   closes. Escape closes it while focus is inside it.

   To assistive technology the callout is a non-modal dialog named by its
   title, described by its text, with a close action. A theme draws the card as
   the ``face`` part (tool-tip family) with the overlay ``shadow`` beneath and
   the ``beak`` on the side towards the target, pointing at the target's
   centre; ``glyph`` is the close mark. The callout's bounds hold the card and
   the beak, and presses beside the beak pass through.
