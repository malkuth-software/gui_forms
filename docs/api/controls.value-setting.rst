Value setting
=============

Check boxes, radio buttons, ranges, numeric and colour editors, property grids and instrument racks.

.. list-table::
   :class: autosummary longtable
   :widths: 35 65

   * - :cpp:class:`CheckBox <gui_forms::CheckBox>`
     - A box with a caption that the user checks and unchecks.
   * - :cpp:class:`RadioButton <gui_forms::RadioButton>`
     - A round button with a caption that the user selects from a group of exclusive options.
   * - :cpp:class:`ToggleSwitch <gui_forms::ToggleSwitch>`
     - A switch for a setting that takes effect as soon as it is turned, such as "Wi-Fi" on or off.
   * - :cpp:class:`RangeControl <gui_forms::RangeControl>`
     - The shared base of controls that show a number within a bounded range.
   * - :cpp:class:`TrackBar <gui_forms::TrackBar>`
     - A slider the user drags, clicks or steps with the keyboard to pick a value in a range.
   * - :cpp:class:`NumericUpDown <gui_forms::NumericUpDown>`
     - A text field for a number, with up and down buttons that step it.
   * - :cpp:class:`DomainUpDown <gui_forms::DomainUpDown>`
     - A text field with up and down buttons that steps through a list of strings.
   * - :cpp:class:`ColorValueEditor <gui_forms::ColorValueEditor>`
     - A colour field: a swatch beside a text box that edits the colour as hexadecimal text.
   * - :cpp:class:`FlagsValueEditor <gui_forms::FlagsValueEditor>`
     - A drop-down field that edits a flags enumeration as a list of check boxes.
   * - :cpp:class:`PropertyGrid <gui_forms::PropertyGrid>`
     - An inspector that lists and edits the registered properties of the selected controls.
   * - :cpp:class:`PropertyList <gui_forms::PropertyList>`
     - A scrolling list of named settings in collapsible groups, each with a value and an optional editor.
   * - :cpp:class:`InstrumentRack <gui_forms::InstrumentRack>`
     - A wrapping row of compact editing modules, each with an enable switch, a few fields and a status line.
