Commands
========

Buttons, links and command rows.

.. list-table::
   :class: autosummary longtable
   :widths: 35 65

   * - :cpp:class:`ButtonBase <gui_forms::ButtonBase>`
     - The common base of every clickable control: text, image, input and the click.
   * - :cpp:class:`Button <gui_forms::Button>`
     - A push button that carries out an action when the user clicks it.
   * - :cpp:class:`DropDownButton <gui_forms::DropDownButton>`
     - A button with an arrow that asks the application to open a menu.
   * - :cpp:class:`LinkLabel <gui_forms::LinkLabel>`
     - Underlined text that the user clicks like a hyperlink.
   * - :cpp:class:`CommandBar <gui_forms::CommandBar>`
     - A toolbar row of command buttons built from a list of items.
